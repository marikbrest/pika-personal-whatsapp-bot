# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep feedback about the work rather than the
person, and do not harass anyone. Maintainers may remove comments, issues or contributions
that violate this, and may ban contributors who repeatedly do.

Report problems privately via GitHub's private vulnerability/advisory form or by contacting
the maintainer through their GitHub profile.
