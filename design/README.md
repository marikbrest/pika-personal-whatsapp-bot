This directory holds `repo-diagram.svg` — an auto-generated file-tree diagram of the
repository, regenerated on every push to `main` by
[`.github/workflows/repo-diagram.yml`](../.github/workflows/repo-diagram.yml) using
[repo-visualizer](https://github.com/githubocto/repo-visualizer). Not committed by hand;
if it's missing, the workflow hasn't run yet (e.g. right after this file was added) —
push to `main` or trigger it manually from the Actions tab.
